# المتجر الإلكتروني — Arabic E‑commerce (Static)

متجر إلكتروني عربي يعمل بالكامل من المتصفح (Frontend Only)، يحفظ كل البيانات
في `localStorage`، وعند إتمام الطلب يُحوّل العميل تلقائياً إلى واتساب مع تفاصيل
طلبه. مصمم للعمل على **GitHub Pages** أو أي استضافة ثابتة بدون أي خادم.

## المزايا

- واجهة عربية RTL، خط Cairo، ألوان سماوية متدرجة
- لوحة تحكم للأدمن (admin / admin111)
  - إدارة المنتجات (الاسم، الوصف، السعر بالريال، صورة، السعر قبل الخصم)
  - إدارة التصنيفات
  - عرض الطلبات وملخص الأرباح
  - تغيير شعار المتجر واسمه ورقم الواتساب
- سلة تسوق + صفحة دفع تطلب الاسم الثلاثي والجوال
- إرسال الطلب تلقائياً عبر `wa.me` لرقم الواتساب المُعدّ في الإعدادات

## التشغيل المحلي (داخل Replit)

```bash
pnpm --filter @workspace/store run dev
```

## النشر على GitHub Pages

التطبيق يستخدم **HashRouter** ومسار نسبي (`./`)، فيعمل من أي مجلد فرعي.

1. ابنِ المشروع:
   ```bash
   pnpm --filter @workspace/store run build
   ```
2. ستجد الملفات في `artifacts/store/dist/public/`. ارفعها إلى فرع `gh-pages` أو
   إلى `docs/` في مستودعك ثم فعّل GitHub Pages من إعدادات المستودع.
3. زر العنوان: `https://<username>.github.io/<repo>/`. لا حاجة لإعدادات إضافية
   لأن المسارات نسبية والتنقل يعتمد على `#`.
